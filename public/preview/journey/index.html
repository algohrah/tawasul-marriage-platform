    المتابعة مع الإدارة

    التواصل يكون مع إدارة توافق فقط، وليس مع الطرف الآخر.

    للمراجعة فقط: لا تفتح المعاينة محادثة حقيقية ولا ترسل رسائل.

    سجل التجربة

    يوضح التغييرات السابقة والجديدة في هذه الجلسة فقط.

      التأجيل والاسترداد وتعريف تسليم المهر الجزئي تحتاج اعتمادًا قبل الربط الفعلي. لا تغيير في بوابة الدفع أو قاعدة البيانات.

      تأكيد اعتماد المبلغ التجريبي

      هذا تغيير داخل المعاينة فقط، وليس إثبات تحصيل أو تعديلًا لنتيجة التوافق.

      رسالة التنسيق مع الإدارة

      مرجع الطلب لا يثبت هوية المرسل. لا تتضمن الرسالة بيانات الطرف الآخر.
